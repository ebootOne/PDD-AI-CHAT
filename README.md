# 拼多多客服工作台（v0.2）

**桌面客户端**：左店铺栏 + 内嵌店铺页面 + 右侧 AI 助手，Windows / macOS 通用。

在拼多多商家后台的客服页里，给每条买家消息生成**有出处、可直接发**的中文回复候选。默认人工确认发送，自动发送是显式开关且受四道闸限制。

数据留在本机：不读 Cookie、不存密码、会话不出电脑（除非你自己配了 LLM）。

```
买家家                                  你
 │  什么时候发货？                       │
 ├──────────────────────────────────────►│  右侧面板：3 条候选 + 依据
 │                                       │  点「填入输入框」→ 回车
 │◄──────────────────────────────────────┤
```

## 三个部分

| 目录 | 是什么 | 跑在哪 |
|---|---|---|
| `desktop/` | Electron 客户端（界面 + 内嵌浏览器） | 商家电脑 |
| `server/` | 本机网关（知识库/商品/规则/兜底） | 商家电脑 |
| **`../pdd-cs-backend/`** | **服务端（持有模型密钥、调模型、记账）** | 你的服务器 |

本地答不上来时才会调用 `../pdd-cs-backend/`，密钥永远不出服务端。详见 [前后端分离](docs/11-前后端分离与本地运行.md)。

## 形态

只有一种：**桌面客户端**（`desktop/`）。浏览器扩展、网页控制台、模拟客服页都已移除。

---

## 5 分钟跑起来（桌面客户端）

```bash
# 1) 启动本地服务（两个终端之一）
node server/index.js

# 2) 启动客户端
cd desktop && pnpm install && pnpm start
```

默认带一个演示店铺（客户端内置页面）。点「添加店铺」填真实客服页地址即可接上真店。

---

## 配置 LLM（可选）

不配也能用：只走知识库关键词匹配，回复保守但完全离线。

配了以后回复更自然。客户端 → 工作台 →「设置」：

| 项 | 例子 |
|---|---|
| Base URL | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-chat` |
| API Key | `sk-...` |

任何 OpenAI 兼容接口都行（通义、智谱、Kimi、本地 Ollama）。

## 测试

```bash
node scripts/test-engine.js     # 引擎回归，不联网
node scripts/eval.js            # 评测集（18 条真实会话）
node scripts/test-session.js    # 一段完整的测试会话：5 轮问答，打印决策/来源/成本
node scripts/explain.js "能开发票吗"   # 单句全链路追踪
node scripts/probe-accuracy.js  # 40 条口语化问法 + 6 组多轮，产出 eval/accuracy-report.md
node scripts/test-sensitive.js  # 敏感词分层：3 条该拦 + 1 条反例
node scripts/test-commitment.js # 承诺面：3 条该拦 + 1 条反例（有人值守）
node scripts/desktop-e2e.js     # 桌面客户端端到端（需客户端带 --remote-debugging-port=9335 启动）
```

演示店里还有「＋ 新会话」按钮：清空当前会话、换一个买家，用来反复测试新会话。

### 测试会话（客户端内置）

顶部「测试会话」按钮 → 「＋ 新会话」→ 以买家身份输入。

每条回复下面标出：决策 / 来源（本地·商品·服务端·兜底）/ 语气档 / 置信度 / 点数 / 耗时。

「复制问题单」会把整段对话导出成 JSON，粘给开发就能定位修复。测试会话不写复核队列，不污染正式数据。

## 边界（请先读）

- **不替代人工**：默认只填输入框，发送键始终由人按。
- **不编造**：知识库没有的，直接转人工，不给候选。
- **不碰凭据**：不读 Cookie、不存密码、不代登录。
- **自动发送有风险**：平台对自动化操作的态度需自行核实；商用前请读 `docs/03-商业化与资质.md`。
- **知识库里的数字是模板**：85%、16 点、1~2 天这些都要按你店铺的实际情况改，改完再上线。
