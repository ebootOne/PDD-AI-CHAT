1. `pddOrderCapture()` 返回 `hasOrder:true`、`status:已发货`；
2. `courier` 是实际快递公司；
3. `trackingNo` 只取运单号，不把订单号当运单号；
4. 事实包 order 块出现「状态/快递/运单尾号」；
5. 「发货了吗」回答已发货，不编时间；
6. 「我的快递到哪了」给快递 + 尾号 + 订单页口径；
7. 收件人/电话/地址不出现在抓取结果和回复里。
