# 治本思维：从“修这一句”到“修一类能力”

> 黄金集过一条，不代表这类问题解决了。要问的是：换一种问法、换一个商品、换一个平台，还会不会错？

---

## 一、先问三个问题

看到一条错，不急着改回复，先问：

1. 这类问题的**共同结构**是什么？
2. 现在缺的是哪一层**判断能力**？
3. 修完之后，**没见过的同类问题**能不能自己落层？

只修单句 = 把测试原句塞进关键词表，下一句还会错。

---

## 二、五层可复用能力

| 层 | 能力 | 输入 | 输出 | 失效表现 |
|---|---|---|---|---|
| 1 | **切面识别** | 一句话 | 独立诉求列表：价格/数量/状态/时效/用法/行为/地区/售后 | 整句只归一个 intent，漏掉第二个诉求 |
| 2 | **证据覆盖** | 切面 + 事实包 | 每面：有证据 / 缺证据 / 不适用 | 一个面缺证据，整条降级 |
| 3 | **断言拆解** | 回复候选 | 可核验 claim：数字/状态/承诺/范围 | 整条一起判，好坏一起丢 |
| 4 | **局部修复** | 坏 claim + 事实 | 只替换坏 claim，保留好 claim | 一处错，整条 fallback |
| 5 | **范围纪律** | 问句切面 + 回复 claim | 只答被问的切面，不追加 | 问地区，多送一句发货时间 |

一句话：**切面 → 证据 → 断言 → 局部修复 → 范围**。

---

## 三、四个剩余问题的真实归因

| 现象 | 不是“这句话怎么写” | 缺的能力 |
|---|---|---|
| 抽纸多少钱、多少抽 → 整条价格页面口径 | 价格有证据、数量缺“抽”的证据 | 切面拆分 + 证据覆盖 + 局部修复 |
| 一根能用多久 → 页面口径 | 问的是“耐久/使用时长” | 切面识别 + 证据覆盖（缺证据要明确） |
| 鹦鹉不爱啃怎么办 → 答成“哪些鸟能用” | 问的是“行为怎么办”，不是“适不适合” | 切面识别 + 方案知识 |
| 新疆发货吗 → 多送 16 点发货时间 | 只问地区/运费 | 范围纪律 |

修这四条，不是加四个特判，而是补上面五层里的三到四项能力。

---

## 四、未知问题怎么落层

```
新问题
  ├─ 问句理解错了 / 切面漏了 / 单位当成实体     → understand
  ├─ 切面对了，但没取到证据 / 证据过期 / 冲突   → facts
  ├─ 证据对，但说了不该说 / 漏了必须说 / 越界   → judge
  └─ 都对，但表达、顺序、立场不对               → reply / persona
```

三层都放不下，才考虑新开一层；新层必须证明能覆盖**至少三类**问题，不能为一条开层。

---

## 五、验收：3 变体 + 1 反例

每条能力修复必须交：

1. **3 个同类变体**（换问法、换商品、换场景）；
2. **1 个反例**（证明不会误伤原本正确的回答）；
3. 一句归因：缺的是哪层能力；
4. 黄金集通过率变化，而不是“这条过了”。

示例（切面 + 局部修复）：

- 变体：多少钱多少抽 / 一包多少张 / 抽纸多少钱；
- 反例：只问多少钱，不能因为“抽纸”带“抽”就降级；
- 验收：价格保留，只把“抽数”说页面口径。

---

## 六、反模式

- ❌ 把黄金集问句写进关键词；
- ❌ 一个场景加一个 if；
- ❌ 答错就整条 fallback，不区分哪句错；
- ❌ 用更热情的措辞掩盖没证据；
- ❌ 只修到“这条测试绿了”，不写能力归因。
