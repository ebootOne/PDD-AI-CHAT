## 二、这一轮修掉的机制（不是句子）

| 问题 | 缺的思维 | 改法 |
|---|---|---|
| 「你好，今天拍的能发吗」被当成招呼，答非所问 | 焦点 + 归一化 | 招呼只在**整句**是招呼时成立；礼貌前缀（请问/你好/老板/在吗）先剥离再理解 |
| 「菠菜多少钱」「胡萝卜多少钱」不报价，或答“以页面为准” | 组合（商品+属性） | 问价走商品目录直报价格；**服务端不得覆盖目录里的权威报价**（之前置信度 0.63 → 被模型改写） |
| 「便宜点」和「多少钱」混为一谈，问价答优惠券 | 焦点 | 拆成 `price`（要数）与 `nego`（要优惠），回复信号分开校验 |
| 「少发了一袋」「收到就坏」被当成不发芽，回“发照片判断” | 槽位（售后子类型） | 售后应答必须覆盖少发/漏发/错发/包裹，不再一律套不发芽流程 |
| 「都三天了还没发」只回规则，没安抚 | 立场 | 情绪催办必须有“歉意 + 动作”，否则换成催办模板 |
| 「请问包邮吗」召回失败 | 归一化 | 礼貌前缀剥离后才检索 |
