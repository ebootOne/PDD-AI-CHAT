# 三级缓冲：没有人工客服时，怎么接住退款和投诉

> 前提变了：**我们没有人可以转**。所以"转人工"不是出路，任何一句话都必须能发出去。
> 原则：先共情、再问清、给办法、最后才给出口。

---

## 一、三级

| 级 | 什么时候 | 回什么 | 例 |
|---|---|---|---|
| **L1 问** | 第一次说退款 | 共情 + 问具体问题 | 亲，是遇到什么问题了呢？您方便说下具体情况吗，咱们一起看看怎么弄哈。 |
| **L2 给** | 买家说清了问题 | 给可执行方向，不承诺结果 | 亲，您说的情况我记下了哈。如果是商品本身的问题，您先把照片留好，按平台规则走售后就行。 |
| **L3 出口** | 仍坚持 / 直接问怎么退 | 告知自助入口 | 亲，实在不好意思。您可以在订单页点「申请售后」，按平台规则提交哈。 |

阶段不靠内存，从会话里数：

```
提过 3 次退款                → L3
说清问题后还坚持             → L3
说清了问题                   → L2
只说"我要退款"               → L1
问"怎么退款"                 → 直接 L3（这是在问流程）
```

---

## 二、为什么不能一上来给规则

- 买家第一句「我要退款」，多数是**有情绪**，不是真的要退；
- 直接甩规则＝把他往退款上推，违背商家利益（规则 8）；
- 问一句的成本极低，挽回的概率很高。

---

## 三、质检层的豁免

三级缓冲的句子天然"没有答案"，所以这几项检查对它放行：

| 检查 | 为什么豁免 |
|---|---|
| 依据 | 问句不需要依据 |
| 对题 | 问句本来就不含 topic 信号 |
| 制造下一轮 | 问一句是产品要求 |
| 劝退 | 引导售后是 L3 的设计 |

豁免只对 `buffer` 标记的回复生效，不放松其他路径。

---

## 四、和"没有人工"的关系

- 全文不出现"转人工 / 安排人 / 稍后回复"；
- L3 给的是**买家自己能操作**的入口，不是"等我们联系您"；
- 转人工只保留在"完全没有产出"的极端情况（未读到消息等），且不扣点。
