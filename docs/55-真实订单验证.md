## 测试店铺不能发货，怎么验？

这个测试店铺没有发货能力，拿不到平台真实渲染的「已发货 + 运单号」页面，所以分两层验：

1. **真实 DOM**：待发货分支，真实页面抓到了 `status=待发货`；
2. **解析夹具**：把面板解析抽成纯函数 `desktop/order-parse.js`，用真实面板文本做样本：
   - 已发货 + 中通 + 运单号；
   - 隐藏「没有相关订单」+ 真实订单 → 不能判空；
   - 只有订单号 → 不误当运单号；
   - 收件人/电话/地址不进结果；
3. **下游链路**：用模拟 `order` 走完整 `/api/reply`，验证模型按状态答。

夹具测试：`scripts/test-order-parse.js` 6/6。

**仍未验证**：真实 DOM 的「已发货 + 运单号」分支，需要等一个有发货能力的店铺实际发货后再跑一次。
