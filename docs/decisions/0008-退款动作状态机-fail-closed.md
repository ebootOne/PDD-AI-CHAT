# 决策：退款动作状态机与 fail-closed

- 日期：2026-11-13
- 状态：第 1 步已实现
- 关联：AGENTS.md、0007

## 前提

退款动作是多步 UI 操作，任何一步页面不一致都不能继续点击，更不能先承诺“已申请”。

## 状态机

```
RESOLVED → FORM_OPEN → ORDER_SELECTED → FILLED → SUBMITTED
```

每一步校验：

- 弹窗存在；
- 选中订单号与目标一致；
- 填单返回的类型/原因/金额与预期一致；
- 提交结果由 refundSubmit 验证弹窗关闭。

## fail-closed

任何一步失败：

1. 立即取消退款弹窗；
2. 不提交；
3. 记录 action_abort；
4. 发送安全兜底：订单页 → 申请售后；
5. 不声称“已申请”。
