# 决策：多会话回复调度

- 日期：2026-11-13
- 状态：调度核心已实现，页面适配待接
- 关联：0007、0008

## 目标

多用户同时来消息时，按最早未回复优先，每会话独立 3 分钟计时，不能因为一个动作/一个模型调用拖住其他会话。

## 规则

- 软 deadline 120s：发安全兜底；
- 硬 deadline 180s：转人工；
- 同一条消息幂等；
- 同一店铺同一时刻只允许一个发送任务；
- 回复优先于退款/邀请动作。

## 已实现

`server/reply-scheduler.js`：

- enqueue/markReplied/markFallback/markHuman；
- tick/next；
- acquireSend/releaseSend；
- 去重与快照。

测试通过：

```
reply-scheduler：多会话/最早优先/软硬deadline/去重/单发送 PASS
```
