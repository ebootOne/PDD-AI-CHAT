## 判断

退款和邀请都是真实动作。先做匹配/确认单，不直接点击提交。

## 计划层规则

- 未发货 → 仅退款；
- 已签收 → 退货退款；
- 已发货/待签收 → 收到货不确定，需确认；
- 退款成功 → 不再发起；
- 商品 SKU 必须唯一匹配；无 SKU/多 SKU → 不自动发。

## 补充：邀请 SKU 真实结构

邀请下单弹窗：
- 商品列表：`.goods-item`，含标题/价格区间/加入清单；
- 点击后 SKU 弹窗：`.sku-select-modal`；
- 维度示例：款式、口味；
- 款式值：26年头茬干蒜单果45mm左右；
- 口味值：2条装10头净蒜 / 1头净蒜小蒜装 / 4条装20头净蒜；
- 数量、库存、确定。

因此邀请下单自动化必须先解析 SKU 维度/值，不能按标题直接发。
