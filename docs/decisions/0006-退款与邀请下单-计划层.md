# 决策：退款与邀请下单先做计划层

- 日期：2026-11-13
- 状态：进行中

## 事实

真实页面已出现：
- 退款卡：商家想帮您申请快捷退款；类型退货退款；原因不想要了；金额 ¥9.90；等待消费者确认。
- 邀请卡：商品标题 + 规格 + 价格 + 数量，等待买家发起拼单。

## 判断

退款和邀请都是真实动作。先做匹配/确认单，不直接点击提交。

## 计划层规则

- 未发货 → 仅退款；
- 已签收 → 退货退款；
- 已发货/待签收 → 收到货不确定，需确认；
- 退款成功 → 不再发起；
- 商品 SKU 必须唯一匹配；无 SKU/多 SKU → 不自动发。

## 待确认

“全自动”是指自动发起申请（买家确认），还是自动同意退款。
