## 判断

## 计划层规则

- 未发货 → 仅退款；
- 已签收 → 退货退款；
- 已发货/待签收 → 收到货不确定，需确认；
- 退款成功 → 不再发起；
- 商品 SKU 必须唯一匹配；无 SKU/多 SKU → 不自动发。

## 待确认

“全自动”是指自动发起申请（买家确认），还是自动同意退款。

## 退款自动判断

- 收货状态先从买家话里取：
  - 已到/收到/签收 → 已收到；
  - 没收到/未到/拒收 → 未收到；
  - 没有明确信号 → 保留不确定，人工选。
- 退款理由：
  - 质量/破损/少发/错发 → 质量问题；
  - 不想要/买错 → 不想要了；
  - 缺货 → 缺货；
  - 没提到 → 留空，人工选。
