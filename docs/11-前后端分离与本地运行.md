# 前后端分离：三个部分，各自负责什么

> 日期：2026-11-05
> 目的：把「模型密钥」从客户端彻底拿出去，同时让不懂后端的人也能一条命令跑起来。

---

## 一、三个部分（不是两个）

```
┌─────────────── desktop/ ───────────────┐
│  Electron 客户端（界面、内嵌浏览器）      │   ← 前端
└──────────────────┬─────────────────────┘
                   │ 本机 HTTP
┌──────────────────▼─────────────────────┐
│  server/  本机网关（127.0.0.1:8787）     │   ← 客户端的一部分
│  知识库 / 商品 / 规则 / 改写 / 兜底       │
└──────────────────┬─────────────────────┘
                   │ 只在"不确定"时调用
┌──────────────────▼─────────────────────┐
│  pdd-cs-backend/  服务端（:8788，独立项目） │   ← 后端
│  持有模型密钥 / 调模型 / 记账 / 鉴权      │
└────────────────────────────────────────┘
```

**为什么本机网关不算“后端”**：它跑在商家电脑上，和界面一起发版；密钥放它这里同样会被逆向。
真正的后端是 `pdd-cs-backend/`（独立项目，独立 git 仓库），密钥永远不出这台服务器。

---

## 二、不懂后端怎么跑起来

### 第一步：装 Node（只做一次）

<https://nodejs.org> 下载 LTS，一路下一步。装完终端输入 `node -v` 有版本号即可。

### 第二步：配置

```bash
cd ../pdd-cs-backend
cp .env.example .env        # Windows: copy .env.example .env
```

用记事本打开 `.env`，只改两行：

```
API_TOKEN=随便打一串很长的字母数字
LLM_API_KEY=sk-你的密钥
```

### 第三步：启动

```bash
npm start
```

或者直接**双击** `pdd-cs-backend/start.command`（Mac）/ `start.bat`（Windows）。

看到这一行就成功：

```
[backend] 已启动 http://127.0.0.1:8788
[backend] 模型：deepseek-chat
[backend] 鉴权：需要 Bearer 令牌
```

浏览器打开 <http://127.0.0.1:8788/health>，出现 `"ok": true` 即可。

### 第四步：让客户端连上

工作台 → 设置 → 服务端模型：

- 地址：`http://127.0.0.1:8788`
- 令牌：`.env` 里的 `API_TOKEN`
- 点「测试连接」看到“服务端在线”就好了

## 三、什么时候走服务端

```
本地知识库命中且置信度够 → 本地直接答（0 token、0 成本）
        ↓ 没命中 / 置信度低 / 两条打平
调用服务端 → 模型生成（扣 1 点）
        ↓ 服务端不可用
兜底话术（绝不让买家干等）
```

判定条件（`config.backend.minConfidence`，默认 0.82）：

- `decision === 'fallback'`（本地没答案）
- `confidence < 0.82`
- `ambiguous`（两条知识分差 < 25%）

## 四、实测

**正常链路**（本地答不上 → 服务端）：

```
请求：支持货到付款吗
→ 本地：没命中 → fallback
→ 服务端：返回 3 条候选，confidence 0.86
→ 最终：source=backend，cost=1，扣 1 点
→ 服务端记账：{"deviceId":"local-dev","tokens":1234}
```

**服务端挂了**：

```
→ 仍返回兜底话术，backendError: fetch failed
→ 买家不会因为后端故障被晾着
```

**没带令牌**：`401`。

## 五、安全清单

| 风险 | 做法 | 状态 |
|---|---|---|
| 密钥泄露 | 只在 `backend/.env`，永不下发客户端 | ✅ |
| 未授权调用 | Bearer 令牌；不配令牌时**只允许本机** | ✅ |
| 刷接口 | 每设备 30 次/分钟 | ✅ |
| 明文传输 | 本机开发 http；上线必须 https 反向代理 | ⚠️ 待上线 |
| 隐私 | 只传必要字段；手机号打码；后端**不记会话内容** | ✅ |
| 日志泄露 | usage.jsonl 只记设备/意图/token 数/耗时 | ✅ |
| 令牌旋转 | 改 `.env` 重启即可 | ✅ |
| `.env` 入库 | 已加 `.gitignore` | ✅ |

**上线前必须补的三件**：
1. `HOST=0.0.0.0` + https 反向代理（Caddy/Nginx）；
2. 令牌换成 32 位以上随机串，并做设备级额度（现在只有全局限流）；
3. 用量落数据库（现在是本地 JSONL）。

## 六、为什么不把密钥放在本机网关

有人会想：反正本机网关也是我的代码，密钥放它那儿不就行了？

**不行。** 客户端是发给商家的，密钥在客户端 = 密钥在别人电脑上。任何“加密”都能被逆向，尤其 Electron 的 asar 包只是打包不是加密。

一旦密钥泄露，别人用你的额度、跑你的账单，而且你查不到是谁。

所以：**密钥必须在服务端，客户端只拿令牌。**
