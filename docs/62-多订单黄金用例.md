# 多订单黄金用例（2026-11-10）

两个 mock 订单：

- A：大蒜，已发货，申通 9410
- B：抽纸，已发货，中通 6789

| 用例 | 买家说 | 期望 | 结果 |
|---|---|---|---|
| M01 | 发货了吗 | 两单都覆盖，或问哪一单 | ✅ |
| M02 | 大蒜那单发货了吗 | 只答大蒜单，不串抽纸 | ✅ |
| M03 | 尾号6789那单到哪了 | 只答尾号 6789 | ✅ |
| M04 | 还有吗 | 问哪款并带出大蒜/抽纸 | ✅ |
| M05 | 两单都发了吗 | 两单都覆盖 | ✅ |
| M06 | 大蒜那单到哪了（两单都是大蒜） | 用尾号区分或问哪一单 | ✅ |

## 关键防线

1. **本地只筛候选**：`order-select` 点名商品/订单号时缩单，不决定最终选哪个；
2. **模型决策**：多单/多商品时，模型逐单覆盖或反问；
3. **judge 兜底**：
   - 同商品多单没报尾号 → 换成“尾号9410、6789，您问哪一单”；
   - 多商品问句没带商品名 → 补成“大蒜还是抽纸呀？”；
   - 多包裹只报一个 → 逐包裹补齐。
