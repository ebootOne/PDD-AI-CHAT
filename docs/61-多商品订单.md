# 多商品订单怎么处理

## 一、已做

capture 现在从订单卡解析商品列表：

```json
"items":[
  {"title":"26年金乡大蒜……","spec":"45mm","qty":"x1","price":"￥9.90"}
]
```

字段来自 `.goods-name / .goods-spec / .goods-num / .goods-price`。

## 二、多商品未点名

买家问「还有吗 / 有货吗 / 多少钱」，订单里有多件，且这句话没点名：

> 亲，您问的是金乡大蒜还是抽纸呀？

- 本地生成，不调模型；
- 只问一句，带「呀」，不承诺动作；
- judge 放行这个澄清问句（`clarify=true`）；
- 算一次回复，满足 3 分钟。

买家点名「大蒜还有吗」→ 走正常商品匹配，不反问。

## 三、当前边界

- 只解析**第一张订单卡**的商品列表；
- 多包裹物流还没做：`courier/trackingNo` 仍是单值；
- 没有真实多商品订单，只用 mock order 验证；
- 商品卡发送 action 还没接。
