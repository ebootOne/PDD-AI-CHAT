# 话术风格：不是禁用清单，是改写

> 修正：上一版把「你/不知道/随便」当成硬禁用词，命中就整条作废。
> 这是错的——**作废等于白丢一条本来能用的回答**，而且穷举永远举不完。
> 现在改成：**检测 → 改写 → 事实校验 → 最后才兜底，永远有回复。**

![礼貌改写](../docs/screenshots/desktop-rewrite.png)

---

## 一、为什么「禁用」是错的

| 做法 | 结果 |
|---|---|
| 命中禁用词就丢弃 | 一条能用的回答没了，还多一次兜底 |
| 命中就改词 | 只改词不改语气，可能更奇怪 |
| **整句改写** | 保留信息，换说法 |

而且用户说得对：**「您」只是礼貌的一个例子**。真正的规则是「语气得体」，不是「必须出现某个字」。

所以「称呼」做成档位：正式（用您）/ 亲切（可以用你），不是硬规则。

---

## 二、三层改写

| 层 | 做什么 | 成本 | 覆盖 |
|---|---|---|---|
| ① 内置改写表 | 8 条高频生硬说法 → 礼貌说法 | 0 | 头部 |
| ② 模型润色 | 表里没有的，交给模型整句改写 | 1 次调用 | 长尾 |
| ③ 兜底话术 | 模型也没有 / 改坏了 | 0 | 极端情况 |

**关键：没有一步是"丢弃"。** 最坏也只是换成兜底话术，但一定发得出去。

### 事实校验（防止改错）

模型改写后必须过一道检查：

```
数字必须一致：85% → 85%，不能变成 90%
否定必须一致：不能退 → 不能退，不能变成可以退
```

不通过就放弃这次改写，退回兜底。**宁可不说，不能说反。**

---

## 三、实测

```
原句（知识库里的懒汉话术）：不知道，你自己看商品页。

改写后：这个我帮您确认一下，您可以先看一下商品页。
改写记录：不知道→这个我帮您确认一下；你自己看→您可以先看一下
剩余问题：0
```

对比旧行为：整条作废 → 发兜底「这个问题我暂时没办法准确回答您」——商家丢了一条本来能用的回答。

---

## 四、一个必须承认的局限

内置表改写能保证「不失礼」，但**不保证读起来自然**：

```
"随便浇浇就行" → "都可以浇浇就行"   ← 不失礼，但有点怪
```

要读起来自然，必须走模型润色。所以：

- 不配模型：安全但偶尔生硬；
- 配了模型：生硬的长尾会被润色掉。

---

## 五、成本账（商人视角）

假设一天 1000 条回复，其中 8% 需要改写：

| 路径 | 条数 | 成本 |
|---|---|---|
| 内置表改写 | 800 | 0 |
| 模型润色 | 200 | 约 0.8 元/天 |
| 兜底 | 少量 | 0 |

**大部分靠表，少部分靠模型，成本可控。** 如果反过来（全部靠模型润色），一天要多花 4 块，一年 1400，没必要。

## 七、语气档位（register）：四种场合，四种"礼貌"

「礼貌」不是一个要求，是四种场景下的四种行为：

| 档位 | 触发 | 该有的行为 | 不能做的 |
|---|---|---|---|
| **标准** | 普通咨询 | 直接给答案、用您、不命令 | 啰嗦、堆感叹号 |
| **歉意** | 催单 / 售后 / 投诉 | 先承认让对方等了，再给动作 | 承诺时间、认责、说"马上到" |
| **热情** | 夸奖 / 感谢 / 复购 | 回应情绪，别只回"不客气" | 好评返现、油腻 |
| **专业** | 规格 / 用法 / 对比 | 先结论、再依据 | 夸大、绝对化 |

实现：

- 判定：买家原话 + 意图 + 风险 → 档位（`server/tone.js`）；
- 影响三处：提示词约束、候选排序（歉意档把"安抚"那条提到第一）、面板显示；
- 商家可逐档关闭，关掉后回落到标准档。

![语气档位](../docs/screenshots/desktop-tone.png)

### 为什么只做四档

- 档位越多，商家越管不过来（他不会配 10 套话术）；
- 模型在 4 档内切换稳定，10 档会串味；
- 每多一档就多一组评测用例，维护成本线性上涨。

### 关于「商家自己加档」

不建议开放"随便加"，理由见对话：加出来的档没有判定信号、模型不会稳定执行，最后变成设了但从不触发的摆设。

替代方案：**人设（persona）与语气档（tier）分离**。

| | 谁说了算 | 内容 |
|---|---|---|
| 人设 | 商家随便改 | 称呼、口头禅、emoji、句子长短 |
| 语气档 | 固定 4 个 | 场景与风险决定，措辞可改但不可新增 |
