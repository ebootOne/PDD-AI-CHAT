# 多店铺隔离

> 目标：A 店的商品，绝不能出现在 B 店的价格/库存/匹配里。

---

## 一、数据

商品字段：

```json
{ "goodsId": "...", "storeId": "smw8rjgmx", "title": "...", "price": "1.85", ... }
```

- 历史种子商品（无 storeId）已全部归到 `demo` 店；
- 当前分布：demo 16、smw8rjgmx 2、real 2；
- 新建商品必须带 storeId。

---

## 二、接口

`GET /api/products`

| 参数 | 返回 |
|---|---|
| `?storeId=smw8rjgmx` | 只返回这家店的商品 |
| `?storeId=demo` | 演示店 16 条 |
| `?all=1` | 全部（仅内部脚本同步用） |
| 不带参数 | `[]`，不再把别家商品暴露给默认调用 |

`POST /api/products` 仍是整表保存，供同步脚本合并后写回。

---

## 三、引擎

- 商品匹配只在本店商品里做：`productStore.forStore(storeId)`；
- 无 storeId 的调用不拿商品；
- 事实包绑定说明书时同样只在 store 作用域内找。

实测：

```
smw8rjgmx 问多少钱 → 1.85 元起（本店商品）
smw8o8zx0 问多少钱 → 页面口径（该店没有商品数据）
```

---

## 四、前端

- 商品 Tab 请求带 `storeId`；
- 过滤规则改成严格 `p.storeId === activeId`，不再把无主商品显示给所有店。
