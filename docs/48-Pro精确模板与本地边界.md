# Pro 模板：四个常用 + 本地边界

> 去掉整句精确表。模板只保留四个最常用的，命中就原话回复；带条件的交模型。

---

## 一、四个模板

| 模板 | 回答 |
|---|---|
| 发货时间 | 当天16点前付款的订单当天发出，16点后顺延到第二天 |
| 快递公司 | 默认中通，偏远地区发邮政 |
| 包邮/运费（无地区） | 除新疆西藏内蒙古外全国包邮，超出按实际运费补 |
| 发票（普票） | 电子普票，订单里填抬头和税号 |

**只有这四个。** 支付、退换、售后暂时不做模板。

---

## 二、怎么命中

用「常见说法 + 守卫」，不维护整句精确表，也不做意图引擎（先不管）。

- 发货时间：什么时候/啥时候/多久/几天/几点 + 发货/发出/发；发货要多久；发货时间
- 快递公司：发什么/什么/哪家/哪个 + 快递；快递公司；什么物流
- 包邮：包邮/运费/邮费/免运费
- 发票：发票/开票

前缀、问号、语气词不影响命中（先归一化再去匹配）。

### 守卫：带这些就不走模板，交模型

| 模板 | 守卫 |
|---|---|
| 发货时间 | 发货了吗、发了吗、发了没、到哪、物流、订单、退款、退货、收到、签收 |
| 快递 | 顺丰、指定、到付、到了吗、到哪、物流、订单 |
| 包邮 | 新疆、西藏、内蒙古、港澳、台湾、海外、偏远、补多少 |
| 发票 | 专票、抬头、税号、公司、纸质、电子 |

## 三、实测

| 问句 | 结果 |
|---|---|
| 请问什么时候发货呀？ | 本地：16点前当天发 |
| 发什么快递 | 本地：默认中通 |
| 包邮吗 | 本地：除偏远全国包邮 |
| 能开发票吗 | 本地：电子普票 |
| 发货了吗 | 模型：先订单页，再补时效 |
| 内蒙古包邮吗 | 模型：内蒙古不包邮，按实际补 |
| 支付宝退款几天能到 | 模型：退款到账以平台规则为准 |
| 支持支付宝吗 | 模型：支持支付宝付款 |

注意最后两条：**支付、退款、地区、专票都不在四个模板里**，统一交模型。要加支付模板，需要单独确认（会变成第五类）。

---

## 四、本地边界

| 类型 | Pro 本地 | 说明 |
|---|---|---|
| 四个政策模板 | ✅ | 符合守卫条件时 |
| 商品字段（价格/库存/规格） | ✅ | 结构化权威数据 |
| 说明书节 | ✅ | 按商品/分节命中 |
| 问候、隐私 | ✅ | 固定口径 |
| 其余（状态/退款/地区/支付/退换/售后/组合） | ❌ | 事实 + 模型 |

普通版同一边界：四个模板 + 守卫 + 权威商品/说明书；调模型时**不带事实包**，所以是笼统回答。

## 六、模板库清空（2026-11-09）

知识库模板库已全部清空，不再内置任何行业/品类模板：

- `server/kb-templates.js`：`TEMPLATES = []`，`CATEGORIES = []`；

- 开店清单/模板建议：`important = { total: 0 }`，界面显示「—」；
- 商家按需**新建知识**即可。

保留的只有**四个回复模板**（server/templates.js）：发货时间、快递公司、包邮、发票。
这两个东西不是一回事：回复模板决定「这句话怎么答」，知识库模板只是「新建知识的示例」。

## 七、普通版定位（已确认）

普通版走 **A 方案**：本地优先，命中不了调模型，但**不带事实包**，所以是笼统回答。
Pro 与普通版的差别是「事实包 + 路由 + 精准回答」，不是「调不调模型」。
